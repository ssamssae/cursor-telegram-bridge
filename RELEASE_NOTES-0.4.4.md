# cursor-telegram-bridge 0.4.4

Customer re-release of the default-off suggestion change.

## What is new since 0.4.3

- Suggested-reply bubbles and Confirm buttons stay off unless you set
  `CUB_SUGGESTED_REPLY_SPLIT=1`.
- When the switch is off, a leftover suggestion tag is removed from the
  answer body instead of being shown as a chip.
- `CUB_SUGGESTED_TAIL_PROMPT` stays off (`0`) unless you turn it on.

Copy-paste command bubbles and ordinary approval buttons are unchanged.
This tag is the installable customer drop. Clone `main` or download the
0.4.4 source archive.
